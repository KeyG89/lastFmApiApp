What it does

A local music memory built from Last.fm scrobbles

The alpha imports listening history into SQLite, enriches artists and tracks with Last.fm tags, and prints early playlist intelligence reports.

01

Full-history import

user.getRecentTracks pages are stored locally and deduplicated by track and timestamp.

02

Music metadata

Artists, tracks, albums, tags, and aggregate play counts are normalized in SQLite.

03

Reports first

Favorites and genre profiles provide the first layer for future playlist generation.

04

Discovery-ready

Spotify and Shazam data can now be linked back to the local music memory.

Tutorial path

Run the alpha in three moves

1. Install

python3 -m venv .venv
.venv/bin/python -m pip install -e ".[dev]"
cp .env.example .env

2. Import

.venv/bin/lastfm-app init-db
.venv/bin/lastfm-app import-history --max-pages 1
.venv/bin/lastfm-app import-history --full

3. Explore

.venv/bin/lastfm-app enrich --artists --limit 100
.venv/bin/lastfm-app report favorites
bash Diagnostics/check.sh

Shazam path

Import discoveries and generate local playlists

Shazam API and synced Spotify playlist imports land in a separate SQLite database, then playlist plans are generated from calm to energetic and by genre coverage.

1. Initialize

.venv/bin/lastfm-app shazam init
.venv/bin/lastfm-app shazam api-check

2. API import

.venv/bin/lastfm-app shazam api-search "artist track" --limit 5
.venv/bin/lastfm-app shazam import-spotify-playlist PLAYLIST_ID --link-lastfm

3. Playlists

.venv/bin/lastfm-app shazam playlists --show
.venv/bin/lastfm-app shazam playlists --show --limit 20
