What it does

A local music memory built from Last.fm scrobbles

The alpha imports listening history into SQLite, enriches artists and tracks with Last.fm tags, and prints early playlist intelligence reports.

01

Full-history import

user.getRecentTracks pages are stored locally and deduplicated by track and timestamp.

02

Music metadata

Artists, tracks, albums, tags, and aggregate play counts are normalized in SQLite.

03

Reports first

Favorites and genre profiles provide the first layer for future playlist generation.

04

Discovery-ready

Spotify and Shazam data can now be linked back to the local music memory.

Tutorial path

Run the alpha in three moves

1. Install

python3 -m venv .venv
.venv/bin/python -m pip install -e ".[dev]"
cp .env.example .env

2. Import

.venv/bin/lastfm-app init-db
.venv/bin/lastfm-app import-history --max-pages 1
.venv/bin/lastfm-app import-history --full

3. Explore

.venv/bin/lastfm-app enrich --artists --limit 100
.venv/bin/lastfm-app report favorites
bash Diagnostics/check.sh

Spotify safety path

Authorize, mirror, dry-run, then create

PKCE keeps the client secret out of the repository. New playlists default to private, while unknown and older playlists remain protected.

1. Authorize

.venv/bin/lastfm-app spotify auth

Register http://127.0.0.1:8765/callback in the Spotify app first.

2. Mirror

.venv/bin/lastfm-app spotify sync --limit 10 --delay 3
.venv/bin/lastfm-app spotify playlists

3. Dry-run

.venv/bin/lastfm-app spotify create --preset morning-rock-bangers --dry-run

Remove --dry-run only after reviewing matches and authorizing the remote write.

Shazam path

Import discoveries and generate local playlists

Shazam web CSV imports land in a separate SQLite database, then playlist plans are generated by energy and genre coverage before Spotify export.

1. Initialize

.venv/bin/lastfm-app shazam init
.venv/bin/lastfm-app shazam status

2. Import CSV

.venv/bin/lastfm-app shazam import <path-to-shazam.csv> --link-lastfm
.venv/bin/lastfm-app shazam enrich-lastfm

3. Spotify

.venv/bin/lastfm-app shazam playlists --show
.venv/bin/lastfm-app shazam export-spotify --no-match --delay 10 --show

The export command creates remote playlists and needs explicit authorization.
